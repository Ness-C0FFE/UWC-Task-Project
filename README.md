# UWC-Task-Project
## Simple To-Do List Application (CLI)

This is one of the most rewarding projects I have built so far, as I applied all the core Python concepts I have learned to build it from scratch. 

It took me three days of hard work to design the logic and handle the flow. While it is a continuous learning process and still has room for optimization, it remains my favorite project because it represents a major milestone in my programming journey.

### 🛠️ Built With
- **Python** (Console/CLI-based)

### ✨ Key Features
- Add, update, and remove daily tasks.
- Track completed tasks directly from the terminal.
